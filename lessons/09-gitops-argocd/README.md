# שיעור 9: GitOps — הריפו מנהל את ה-cluster

## מה לומדות בשיעור

- הצעד האחרון שעוד עשינו ביד, וסחף (drift): כשה-cluster מתרחק מ-Git
- מה ההבדל בין push ל-pull, ולמה ה-pipeline לא יכול פשוט להתקין
- גישת GitOps: ארבעה עקרונות, ומנהלת הסניף שמסתכלת על לוח ההזמנות
- הכלי Argo CD: התקנה עם Helm, כניסה לאתר, ו-`Application` ראשון
- שתי שאלות על כל Application: Synced או OutOfSync, Healthy או Degraded
- לשנות רק דרך Git: REFRESH, DIFF, וסנכרון אוטומטי
- תיקון עצמי (self-heal), ניקיון (prune), וחזרה אחורה עם `git revert`
- המעגל המלא: job של `deploy` שכותב את התגית ל-Git
- אותו pipeline ב-GitLab CI, ולמה ל-Argo CD לא אכפת

## איך השיעור עובד

בשיעור: הרצאה והדגמות על המחשב שלי. אתן עוקבות במדריך, ושואלות. את הכל מתרגלות בבית.

6. לתרגם ל-GitLab CI (15 דקות)
